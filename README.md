# Dad's 60th Birthday Cloud Studio 🎬🎂

אפליקציית ענן עצמאית ואינטראקטיבית ליצירה, עריכה, ניהול והצגת סרטון ומצגת יום הולדת 60 לאבא צחי.

## ✨ פיצ'רים עיקריים
- 📺 **נגן קולנועי 16:9** עם אפקט תנועה דינמי (Pan & Zoom Ken Burns), טשטוש רקע אלגנטי ומוזיקת רקע.
- 🔀 **שליטה מלאה בציר הזמן (Timeline)**: גרירה ושחרור (Drag-and-Drop) לשינוי סדר, קפיצה מהירה למיקום, העברה למקום 1 וסינון לפי פרקים.
- ➕ **הוספת תמונות חדשות**: העלאת תמונות ישירות מהמחשב או הנייד והוספתן לשקפים בזמן אמת.
- 🗑️ **מחיקה ועריכה**: מחיקת שקפים, שינוי כיתובים, ציטוטים וזמני תצוגה.
- 🖼️ **התאמת פריים מתקדמת**: זום/הגדלה (40%-250%), הזזה אופקית ואנכית, סיבוב 90° וניקוי שולי אלבום.
- 🎨 **צביעת AI אותנטית (Google Gemini AI)**: צביעה של 100% מהדמויות והרקע בתמונות שחור-לבן בצבעים טבעיים וחיים.
- ☁️ **שמירה דינמית בענן**: סנכרון ל-LocalStorage ול-GitHub API, לצד ייצוא וייבוא מלא של קובצי JSON.

## 🚀 פריסה (Deployment)
האפליקציה בנויה לפריסה מיידית ב-Vercel או ב-GitHub Pages.

## מצגת: מעברים, מוזיקה, ייצוא MP4

- **מעברים:** כל שקף יכול לקבל דיסולב, גלילה, דחיפה, כיסוי, זום או פייד לשחור. בזמן ניגון התמונה גם זזה לאט (Ken Burns). ברירת המחדל למהירות היא שנייה אחת.
- **מוזיקה:** אותו שיר ממשיך ברצף בין שקפים. הוא נעצר רק בהשתקה, בהשהיית המצגת, במעבר לשיר אחר, או בזמן שקף וידאו (הסאונד של הסרטון תופס את מקומו, והשיר חוזר מאותה נקודה אחריו).
- **תנועת תמונה:** בזמן ניגון התמונה צוללת לאט כלפי מטה. בפורטרט גבוה מתחילים על הפנים ויורדים בלי לחתוך את הראש.
- **הורד MP4:** כפתור «הורד MP4» פותח את המצגת במסך מלא ומקליט בזמן אמת (1920×1080). «עצור ושמור» שומר חלק, ו«המשך הקלטה» ממשיך מהשקף שלא הושלם. «בטל הקלטה» עוצר בלי לשמור את החלק הנוכחי. הדפדפן לא מדביק לתוך קובץ MP4 פתוח, אז מאחדים חלקים כך:

```bash
bash scripts/concat_mp4_parts.sh dad-60-parts.json
```

אם נגן טלוויזיה לא פותח את הערוץ הקולי, המירו ל-AAC:

```bash
bash scripts/make_compatible_mp4.sh dad-60-birthday.mp4
```
