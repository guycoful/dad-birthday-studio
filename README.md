# Dad's 60th Birthday Cloud Studio 🎬🎂

אפליקציית ענן עצמאית ואינטראקטיבית ליצירה, עריכה, ניהול והצגת סרטון ומצגת יום הולדת 60 לאבא צחי.

## ✨ פיצ'רים עיקריים
- 📺 **נגן קולנועי 16:9** עם אפקט תנועה דינמי (Pan & Zoom Ken Burns), טשטוש רקע אלגנטי ומוזיקת רקע.
- 🔀 **שליטה מלאה בציר הזמן (Timeline)**: גרירה ושחרור (Drag-and-Drop) לשינוי סדר, קפיצה מהירה למיקום, העברה למקום 1 וסינון לפי פרקים.
- ➕ **הוספת תמונות חדשות**: העלאת תמונות ישירות מהמחשב או הנייד והוספתן לשקפים בזמן אמת.
- 🗑️ **מחיקה ועריכה**: מחיקת שקפים, שינוי כיתובים, ציטוטים וזמני תצוגה.
- 🖼️ **התאמת פריים מתקדמת**: זום/הגדלה (40%-250%), הזזה אופקית ואנכית, סיבוב 90° וניקוי שולי אלבום.
- 🎨 **צביעת AI אותנטית (Google Gemini AI)**: צביעה של 100% מהדמויות והרקע בתמונות שחור-לבן בצבעים טבעיים וחיים.
- ☁️ **שמירה דינמית בענן**: סנכרון ל-LocalStorage ול-GitHub API, לצד ייצוא וייבוא מלא של קובצי JSON.

## 🚀 פריסה (Deployment)
האפליקציה בנויה לפריסה מיידית ב-Vercel או ב-GitHub Pages.
